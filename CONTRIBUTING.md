# Contributing to RN-Toast

Thank you for considering contributing to RN-Toast! Here are some guidelines to help you get started.

## Getting Started

1. Fork the repository and clone it locally.
2. Install dependencies using `npm install` or `yarn install`.
3. Run the project locally to ensure everything works as expected.

## Code Style

This project uses ESLint and Prettier for code formatting and linting. Please ensure your code adheres to these standards by running:

```bash
npm run lint
npm run format
```

## Testing

Write tests for any new features or bug fixes. Run tests using:

```bash
npm test
```

## Pull Requests

1. Create a new branch for your feature or bug fix.
2. Commit your changes with clear and concise commit messages.
3. Push your branch and open a pull request against the `main` branch.

## Issues

Feel free to open an issue if you encounter a bug or have a feature request. Please provide as much detail as possible.

## Code of Conduct

Please be respectful and considerate of others while contributing to this project.

Happy coding!
